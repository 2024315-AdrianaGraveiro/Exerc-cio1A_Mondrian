# Reflexão parte A

Usei um canvas de 800 × 784 px para respeitar a proporção do quadro, que não é quadrado. As posições e espessuras das linhas foram medidas na imagem de referência e mantidas diferentes entre si, porque essa irregularidade faz parte da pintura. As cores foram amostradas da obra (branco quente e preto suavizado, em vez de valores puros) para se parecerem com tinta sobre tela. Para a textura, sobrepus retângulos semitransparentes com desfoque, que criam variações tonais suaves sem ruído agressivo. Escrevi o código em sequência, sem ciclos, para que cada medida fique visível e fácil de ajustar.
